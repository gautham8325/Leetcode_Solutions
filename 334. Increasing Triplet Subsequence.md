# Intuition

The problem involves finding an increasing triplet subsequence in an array. The first thought is to use two variables to keep track of the smallest and middle elements encountered so far, and check if we can find a third element that is greater than both.

## Approach

1. **Initialization**: Initialize two variables, `smallest` and `mid`, to `Integer.MAX_VALUE`. These variables will keep track of the smallest and middle elements encountered so far.
2. **Iteration**: Iterate through the array. For each element:
   - If the element is less than or equal to `smallest`, update `smallest`.
   - Else if the element is less than or equal to `mid`, update `mid`.
   - Else, return `true` because we have found an element greater than both `smallest` and `mid`, indicating an increasing triplet subsequence.
3. **Return**: If no increasing triplet subsequence is found, return `false`.

## Complexity

- Time complexity:
  The time complexity is $$O(n)$$, where $$n$$ is the number of elements in the array. This is because we iterate through the array once.

- Space complexity:
  The space complexity is $$O(1)$$, as we are using a constant amount of extra space.

```java []
class Solution {
    public boolean increasingTriplet(int[] nums) {
        /*

            int prev = nums[i-1];
            int next = nums[i+1];

                return true;
            }
        }
        return false;
        */
        int smallest = Integer.MAX_VALUE;
        int mid = Integer.MAX_VALUE;
        for(int number : nums){
            if(number <= smallest){
                smallest = number;
            }else if(number<=mid){
                mid = number ;
            }else{
                return true;
            }
        }
        return false;
    }
}
```
